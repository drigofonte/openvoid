Application rules

4 principles When tokens aren't enough — these guardrails keep the system honest.
Accent only for live. Running sessions, active steps, focus rings.
Green only for prod. Production state, deploy success.
Black for primary CTA. One per screen, max.
Mono for identifiers. URLs, ids, kbds, code. Never product names.
